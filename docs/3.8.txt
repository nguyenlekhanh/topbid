IMPLEMENTATION NOTES:
The first run exposed a thenable-proxy pitfall: a universal chain proxy makes the CLIENT itself thenable, so await createClient() unwrapped it into a queue result (supabase.from is not a function). Fixed with the client/builder proxy split described above. One unused module-level type removed after lint flagged it; one Prettier line-break auto-fixed via lint:fix. Queue semantics are strict FIFO: tests enqueue exactly the responses a flow consumes, so unexpected extra queries fail loudly (empty queue resolves null data rather than silently passing - acceptable trade-off documented here).
