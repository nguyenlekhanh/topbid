OBJECTIVE:
Add the Stripe webhook endpoint: a server-only POST route that receives events, verifies signatures against STRIPE_WEBHOOK_SECRET using the raw request body, and routes only the plan-required event types with correct HTTP semantics.

SCOPE:
- New src/lib/stripe-webhook.ts - processStripeWebhook(payload, signature): WebhookProcessingResult containing ALL trust-boundary and routing logic (testable without HTTP)
- New src/app/api/webhooks/stripe/route.ts - thin POST adapter: reads request.text() RAW (never parsed/re-serialized before verification), forwards signature header, maps result status/body to NextResponse; explicit runtime = 'nodejs'
- Event routing: checkout.session.completed is acknowledged with linkage extraction (session id, client_reference_id, metadata.bid_id) logged for downstream tasks; all other types acknowledged+ignored (200)
- HTTP semantics: 200 verified (handled or ignored); 400 missing payload/signature or failed verification; 500 missing webhook secret config or unexpected processing failure (Stripe retries)

- Payment-status verification (Task 4.7), pending->paid conversion incl. stripe_payment_intent_id/is_highest writes (Task 4.8), event-id idempotency ledger (Task 4.9), failure/refund handling (4.10/4.11), deeper signature review/hardening (4.6)
