IMPLEMENTATION NOTES:
Extended src/lib/bids.ts following existing conventions (async createClient, field allowlist). Query: .from('bids').select(`${BID_FIELDS}, categories (id, slug, name)`).eq('status','paid').order('amount',{ascending:false}).order('created_at',{ascending:false}).limit(limit). Embedded rows cast via `as unknown as` because generated DB types are absent (Supabase infers embeds as arrays). Rank assigned by array position (1-based) after sorting. Default limit 10; invalid/non-finite limits fall back to 10. No per-category dedup — plan does not specify it; consumers may pass any limit.
