# Topbid.lol

A simple public bidding/leaderboard website where users bid on categories and compete for the top spot.

## Quick Start

```bash
# Install dependencies
npm install

# Set up environment variables
cp .env.example .env.local

# Run development server
npm run dev
```

## Technology Stack

- **Framework**: Next.js 14+ (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Database**: Supabase / PostgreSQL
- **Payments**: Stripe
- **Deployment**: Vercel
